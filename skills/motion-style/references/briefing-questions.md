# Briefing Questions

Use existing briefs, source assets, selected direction, and project settings before asking. Ask one compact set only for missing information that materially changes correctness, output, or scope.

## Relevant gaps

- Deliverable and role: brief, prompt, local edit, whole-frame motion, element-level motion, or finished animation?
- Exact on-screen text/data and which wording may change?
- Canvas, duration, actual audio, output format, sound/alpha/source-file requirements?
- Existing assets and which internal elements need independent control?
- Any consequential style choice not already determined by the project or request?

For early D movement intent, decide what changes and which assets need control without requiring a finished composite. Detailed D choreography follows the real-content composite. C whole-frame motion does not require layering.

## Reasonable defaults

When unspecified and consistent with the request, use a 16:9, approximately 6-second finance/documentary fragment with a clear movement, emphasis and readable hold. Inherit palette and selected tone. State material assumptions; supplied dimensions, duration, audio, style and tool always take precedence. Distinguish an explicitly silent piece (timing may be fixed) from pending narration (audio-dependent timing remains provisional).

## Exploration only when useful

For an exploration request or unresolved consequential choice, compare a suitable number of distinct directions such as restrained documentary, clean explainer, or data-news pacing, with the effect on comprehension. A settled direction or complete-delivery request does not require an extra 2-3-option round. Wait only at a user-reserved selection point.
