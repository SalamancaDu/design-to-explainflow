# 标题文字设计系统参考

本参考沉淀标题字设计方法，不沉淀固定风格。它的目标是解决两类问题：一是“设计语言看似正确，但生图跑向 3D、队徽、古早纹理、错字”；二是“字做得好看，但缺少像参考图那样与主题强相关的画龙点睛符号”。

## 1. 总原则

标题字不是装饰字，而是主题符号。优秀标题需要同时完成四件事：

1. 远看识别标题。
2. 近看看到主题相关的字形、纹理、符号或副标题细节。
3. 主叙事符号准确，不只是漂亮装饰。
4. 能扩展到封面、片头、章节卡、社交图和透明 PNG 资产。

参考图里的热带、犯罪、鱼市、海洋、印度、首尔等不是固定风格库，而是“具体主题 → 叙事判断 → 字体基底 → 主符号 → 版式层级”的结果。下一次任务必须重新推导，不得默认沿用任何案例的颜色、纹理或符号。

## 2. 设计依赖与交付条件

流程与审批条件以 [SKILL.md](../SKILL.md) 为准；本参考提供设计方法和按需模板，不再定义另一套固定候选数量或等待节点。

新字形设计依次解决主题与用途、叙事符号、字体骨架、逐字结构、视觉记忆点与可执行性、准确语言层及材质。探索请求比较不同路线；完整交付请求可直接选定合适路线继续。只有用户明确保留的选择或审阅节点需要等待。

中性背景预览用于检查字形、层级和可读性，并非所有请求都要单独交付的首轮。透明资产优先使用所选工具的原生透明能力，检查实际 Alpha 与目标背景上的边缘；需要替代方法时才使用色键去底。

已有标题的透明导出或局部修改，继承选定字形与准确文本，只检查受影响部分；不重新要求多方向探索或逐字重设计。只要提示词时交付提示词，不宣称生成与视觉检查已经完成。

## 3. 参考图的正确使用方式

从参考图中提取“机制”，不要提取“固定样式”。

可提取：

- 标题如何把主题压缩成一个符号。
- 符号是进字内、穿过字形、叠在线稿层，还是作为英文副标题关系出现。
- 中文主标题、英文副标题、编号、局部符号之间如何分层。
- 质感如何服务主题，而不是装饰表面。

不可默认沿用：

- 某张图的固定配色。
- 某个题材的图标，如海浪、鱼、枪、地图、手、球场线。
- 某种旧化、颗粒、飞白或脏污强度。
- 某种英文字体，如手写体、窄长大写、运动字。

例子：

- “首尔夏天”的核心不是地图风，而是三八线与南北关系被压进标题结构。
- “印度”的核心不是红黑蓝配色，而是节庆、人物线稿、地方文字与手写英文共同形成层级。
- 任何新主题都不应自动等于上一案例的符号；同一主题也可以根据叙事判断生成多条路线，如结构线、档案层、地域文字、人物线稿、物件负形或材质机制。

## 4. 主叙事符号候选

当用户要求探索或保留路线选择时，按实际需要比较主叙事符号；3-5 套可作为深入探索的示例数量，不是最低要求。完整交付且未指定路线时，使用下列维度选定合适路线，不强制展示未采用的候选。

每套必须包含：

- **路线名**：一句话说清视觉 premise。
- **象征意义**：它表达主题里的哪一层判断。
- **字形融入方式**：进入内白、笔画切口、底线、线稿层、框架、负形、一个关键偏旁，还是与副标题形成关系。
- **英文 / 本地语言层**：是否需要；如果需要，是解释、诗性反差、地点、编号、章节，还是节奏线。
- **字体基底方向**：宽扁重黑、现代片名手写、粗笔刷飞白、宋体碑刻、复古招牌、票券章回、窄长无衬线、地方文字混合等。候选之间必须有明显骨架差异，不能全部是方正重黑。
- **配色 / 材质方向**：探索阶段给出方向；完整交付或路线已定时继承选定方案。
- **风险**：可能俗套、字面化、不可读、跑向 Logo、跑向插画或跑偏主题的地方。

默认策略：

- 用户要求探索：比较有区别的候选；明确保留选择时等待该节点。
- 用户要求完整交付或“你来决定”：选定合适路线继续，简述影响结果的取舍；开放主题本身不形成审批节点。
- 用户已给明确路线：不强行扩展多方案，直接进入字体基底关。

## 5. 字体基底探索关

字体基底探索关用于防止所有方案都落回同一种方正重黑。开放主题下，字体本身就是叙事路线的一部分，不是最后的美化。

规则：

- 主叙事符号候选必须同时给出字体骨架差异。
- 比较候选时使用明显不同的字体骨架，数量由探索目标决定；完整交付或已选字体不要求额外候选。
- 不允许 3-5 套方案全部使用宽扁重黑、现代粗黑或方正粗黑。
- 进行候选探索且主题适合时，考虑现代片名手写 / 粗笔刷飞白；已选路线或直接交付不额外添加候选。
- 如果连续几版都像同一种字体，停止继续改 prompt，先回到字体基底探索。
- 每个字体候选都要说明它改变了什么：情绪、叙事、可读性、主题符号融入方式和风险。

常见探索组合：

- 宽扁重黑：结构、现实、压迫、纪录片硬度。
- 现代片名手写 / 粗笔刷飞白：人味、情绪、命运、旅途、伤口、反差喜剧。
- 宋体 / 明体 / 碑刻：历史、档案、地理、文化追问。
- 复古招牌 / 票券章回：市井、人文、人物小传、旧时代秩序。
- 工业 stencil / 窄长无衬线：纪律、行动、训练、机械、冷静。
- 地方文字混合：地域身份、跨文化语境、本地真实感。

## 6. 字体基底关

字体基底不是“高级、厚重、有设计感”，而是可执行的字形描述。

必须写清：

- **主标题基底**：现代粗黑体、宽扁重黑、碑刻宋体、毛笔飞白、复古招牌字、工业 stencil、票券章回字、窄长运动字、地方文字混合等。
- **字形比例**：宽扁、瘦长、横向铺展、紧凑、低重心、内白大或内白压缩。
- **笔画性格**：硬转角、斜切口、断笔、飞白、刀刻边缘、印刷磨损、墨迹边缘。
- **结构边界**：哪些笔画可以改，哪些关键识别结构不能改。
- **与主叙事符号的关系**：这个字体为什么能承载所选符号。
- **参考方向**：类似现代粗黑体、思源黑体 Heavy 方向、方正粗黑方向、站酷酷黑方向等。
- **禁止倾向**：普通默认黑体、卡通圆体、游戏 Logo 字、3D 石雕字、金属浮雕字、厚投影字。

商用或高准确度中文标题优先：真实字体渲染基础字 → 风格处理 → 人工修字 / 矢量化。

## 7. 逐字字形设计关

逐字字形设计关用于解决“看起来是手写飞白字，但不像参考级标题设计”的问题。参考级标题不是把一组风格词套到所有字上，而是逐字安排结构、节奏和叙事入口。

必须为主标题每个字写清：

- **角色**：视觉锚点、节奏承接、叙事承载、开场力度、收束重心或辅助。
- **主笔画**：最有识别度的笔画方向、长度、压力、速度和收笔。
- **外轮廓**：远看轮廓、宽高比例、倾斜、裁切、夸张点和整体块面。
- **重心与比例**：单字重量、重心高低、宽窄、密度、与相邻字的节奏关系。
- **内白 / 负形**：哪些空间保留、压缩、打开、切割，哪个负形可以承载主题符号。
- **字间关系**：连接、重叠、留白、基线、气口、共同方向和整体标题气势。
- **主题符号入口**：只选择 1-2 个字或负形作为核心入口；符号必须成为结构，不是贴图。
- **可读性底线**：哪些笔画、偏旁或结构不能变。

现代片名手写 / 粗笔刷飞白体尤其需要这一关。不能只写“现代手写、飞白、粗重、电影感”；必须说明每个字的主笔画和收笔。飞白是最后的材质，不是字形设计本身。

参考级判断：远看有明确大轮廓，近看每个字有分工；主符号集中而准确；英文或本地语言层级明确；缩小后仍然能读。新字形不能只凭风格词进入生图；已有标题的导出或局部编辑继承原字形方案，不重新设计。

## 8. 生成前通用门禁

这四项用于新字形或实质重设计，沉淀判断方法，不沉淀具体主题元素。新设计从当前主题推导符号、颜色、字体和纹理；已有标题的导出或局部修改继承选定方案，只核对受影响部分。

### 视觉记忆点门禁

进入 imagegen 前，必须有一个来自当前主题的视觉记忆点。它可以是线条逻辑、负形变化、副标题关系、地方文字层、结构切口、材质机制或一处图形化笔画。它必须在缩小后仍然能被说清。

不通过：只有情绪词、极细弱线、轻微重心变化、淡淡颗粒或普通装饰点。

### 受控主题锚点门禁

禁止俗套贴图是对的，但不能把主题识别全部删掉。每个方案应保留 1-2 个低密度、结构化、非贴图式主题锚点。锚点必须来自当前主题，可进入内白、笔画切口、基线、框架、副标题层、本地注释、细小结构线或一个关键笔画。

不通过：把所有主题元素都写进 avoid，导致标题只剩普通字体和抽象气质。

### 生图可执行性门禁

判断这套设计是否适合直接交给 imagegen。若设计主要依赖 3%-5% 重心变化、5%-8% 笔画延长、微切角、极细线、细微字距或极弱纹理，生图很可能无法稳定执行。

不通过时，增强可见结构，或改走真实字体底稿、手写底稿、矢量粗稿、后期人工修字路径。

### 反过度禁用门禁

avoid 清单只负责防跑偏，不能负责设计本身。正向 prompt 必须先清楚说明视觉 premise、字体基底、逐字方案、主题锚点、层级、配色和材质。若负向限制比正向设计更具体、更长、更有画面感，应先重写正向设计。

## 9. 常用字体基底

### 宽扁重黑中文

适合：社会议题、城市、劳动、体育纪录片、现实题材、强叙事标题。

要点：字面宽、重心低、横向铺展、粗笔画、硬转角、紧字距。可加少量断笔、切角、印刷磨损、结构线。不要做成石头厚字、游戏标题、金属浮雕或体育队徽。

### 毛笔飞白字

适合：命运、伤痛、旅行、民俗、宗教、历史记忆。

要点：飞白服务情绪，不服务炫技；保留关键笔画；避免狂草导致不可读。

### 现代片名手写 / 粗笔刷飞白体

适合：人物命运、迁徙、旅行、人文、创伤、反差喜剧、地域题材、街头感、情绪性纪录片。

要点：它不是传统书法，也不是武侠题字。它更像现代电影片名：笔势自由但结构受控，粗细变化明显，飞白和断笔服务情绪，主题元素可以藏在收笔、断墨、飞白空隙、局部线稿或小印章里。

可加入的主题元素：地图轮廓、鸟、船、手、伤口、路线、城市边界、地方小字、英文副标题、印章。只选一个核心符号，不要把笔画变成插画拼贴。

风险：AI 容易写错中文，容易变廉价书法、古装剧、武侠风、景区题字或随机飞溅。正式资产建议先用真实手写底稿、选定字体或矢量粗稿，再让 imagegen 做材质和氛围探索。

### 宋体 / 明体 / 碑刻感

适合：历史、地理、古籍、文化追问、长时间跨度。

要点：端正、稳定、纪念碑式秩序；可叠加地图、路线、旧纸、拓印颗粒。

### 复古招牌 / 票券 / 章回边框

适合：人物小传、手艺人、货郎、画匠、民俗故事、旧时代叙事。

要点：可使用边框、编号、票券线、章回结构；装饰线少而准，不能抢主标题。

### 工业 stencil / 窄长运动字

适合：行动、训练、纪律、赛事、街头、工业现场。

要点：可加切角、断连、速度线、编号；中文标题要先保证识别，再谈速度感；不要滑向球衣号码字或美式体育 Logo。

## 10. 英文 / 本地语言层

英文不是装饰，也不是必须项。它的作用必须明确：

- 解释中文标题没有说完的叙事。
- 制造纪录片、杂志、片尾或国际化语气。
- 作为章节编号、地点、日期、档案编号。
- 与主标题形成字体节奏反差。
- 引入地方语言或本地文字，增强地域真实感。

要求：

- 英文或本地语言必须给准确文本，不允许伪字。
- 字体方向必须指定，如 condensed uppercase、small caps、monospaced archival、handwritten script、local-script annotation。
- 层级必须低于主标题，除非用户要求双语同权。
- 不要因为参考图有英文，就给所有标题加英文。

## 11. 主题符号融入规则

主题符号要像设计结构，不要像贴图装饰。

推荐方式：

- 字内低密度线条：地图、路线、时间线、市场结构线、证据线。
- 局部替代笔画：鱼、枪、蛇、道路、岛形、工具等只替换一个关键位置。
- 线稿叠加：人物、建筑、海浪、宗教符号作为前后层线稿。
- 框架化：票券、章回牌、边框、印章增强秩序。
- 副标题关系：英文或本地语言成为叙事解释，而不是随机装饰。

密度控制：先保证标题字面和缩小后的轮廓清晰，将最强符号集中在一两个结构入口；其余字承担节奏与支撑。视觉注意力不作为可精确测量的百分比门槛。给 imagegen 明确可见的结构暗示，避免把完整图案塞入每个字。

禁止：完整球场、城市、建筑、台阶、人物场景塞进字里；主题物件填满所有笔画；符号比字更强；把某个历史案例的符号移植到无关主题。

## 12. 反 3D 与反古早材质规则

除非用户明确要求雕塑、游戏 Logo、金属牌匾或实体字，不要使用：

- 3D extrusion / bevel / embossed lettering
- 石块字、泥土字、假裂纹混凝土、古早游戏标题材质
- 厚投影、环境遮蔽、地面接触阴影
- 立体台阶、球场、建筑模型塞进笔画
- 高光边缘、金属反光、塑料质感
- stock grunge texture、过密污渍、随机脏斑

参考图更接近 2D 平面标题系统：印刷颗粒、飞白、地图填充、线稿叠加、票券边框、旧胶片质感。它们有质感，但不是厚重 3D 材料。

## 13. 提示词模板

### 13.1 主叙事符号候选模板

~~~text
用于我明确要求的探索：基于标题“{标题}”和主题“{主题}”，比较适量且有明显差异的主叙事符号路线。
每套包含：路线名、象征意义、字形融入方式、英文/本地语言层、字体基底方向、配色/材质方向、风险。
候选字体骨架应有明显差异；适合主题时考虑现代片名手写 / 粗笔刷飞白，不为了凑数量加入无关路线。
最后推荐一套，并说明为什么。
~~~

### 13.2 平面预览 prompt

用户请求预览或设计检查需要时使用；不是完整交付的强制首轮。已有可靠字形资产可直接检查或按请求导出。

~~~text
Create a flat 2D Chinese title-card typography asset, not a logo, not a badge, not an emblem, not a game title, not a 3D scene.
Exact main title text: “{中文标题}”.
{Optional exact subtitle text: “{英文或本地语言副标题}”.}
Use a {字体基底} lettering skeleton: {字形比例、重心、笔画性格、内白关系}.
Character-by-character glyph plan: {逐字角色、主笔画、外轮廓、内白/负形、字间关系、主题符号入口、可读性底线}.
Visible design anchor: {缩小后可识别的主题结构、所在字符或笔画及需保留的轮廓；不填写过程检查结论}.
Apply only these transformations: {允许改造}.
Integrate the selected narrative motif as sparse structural hints: {主叙事符号、融入位置、密度}. Do not create a complete scene or diagram inside the letters.
Subtitle treatment: {若有副标题，写字体方向、位置、层级；若无，写 no subtitle, no extra words}.
Texture: {2D 印刷 / 丝网 / 飞白 / 胶片颗粒 / 拓印 / 纸纤维 / 墨迹边缘}. Keep it flat and readable.
Palette: {主标题色、线条色、点缀色、预览背景色}.
Composition: centered title text asset with safe margins, no watermark.
Avoid: 3D extrusion, bevel, embossed lettering, stone carving, metallic effect, thick shadow, logo, badge, fake cracked concrete, mud texture, stock grunge, full scene inside letters, wrong Chinese characters, pseudo-text.
~~~

### 13.3 透明导出 prompt

透明输出已请求或授权时使用，先完成适用的质量检查。只有用户明确保留预览审批时，才等待该审批。

~~~text
Use the selected flat 2D title design or supplied title asset as the reference/edit target. Export only the exact title text asset with a genuine transparent background using native transparency when supported.
Preserve the selected font base, glyph structure, narrative motif, subtitle layer, palette, motif density, and texture; do not redesign the lettering.
Do not bake a colored background, checkerboard, reflection, or ground plane into the asset. Preserve intended internal texture and clean glyph edges.
Keep the title separated from the background with clean edges. Do not change the exact title text or exact subtitle text. No extra words, no watermark, no pseudo-text.
~~~

原生透明不可用或实际结果需要替代方法时，才把透明指令替换为选定的纯色色键背景，确认主体不含该键色，并检查去底后的笔画、纹理及色边。不要把色键方案写成默认导出要求。

## 14. Prompt lint 清单

输出 prompt 前必须检查：

- 阶段：交付与请求一致；预览审批仅在用户保留该节点时适用。透明导出优先原生 Alpha，色键仅是有条件的替代方法；不得宣称未执行的视觉或透明检查。
- 角色：标题资产不得写 Use case 分类头、logo-brand、badge、emblem、team logo，除非用户明确要求。资产角色应写进第一句，例如 flat 2D Chinese title-card typography asset。
- 主叙事符号：必须来自当前主题的选中路线，不得沿用上一案例的战术线、鱼、海浪、手、地图、深炭骨白等固定符号或配色。
- 字体探索：请求探索时比较明显不同的骨架；完整交付或已有字体不强制增加候选。若实际结果反复落入不适合的方正重黑，再回到字体选择。
- 字体：必须包含基底、比例、重心、笔画性格、内白关系，以及它为什么适合该路线。
- 逐字字形：新设计要包含角色、主笔画、轮廓、内白、字间关系、符号入口与可读性边界；只写风格词不通过。导出或局部修改继承现有字形与参考，不重开设计。
- 视觉记忆点：必须有一个来自当前主题、缩小后仍能说清的记忆点；只有情绪词、微弱细线或淡纹理不通过。
- 受控主题锚点：避免俗套贴图，但必须保留 1-2 个低密度结构化主题锚点；不能把所有主题识别都写进 avoid。
- 生图可执行性：必须判断设计是否足够可见；若主要依赖微调百分比、极细线、微切角或细字距，应增强结构或改用字体 / 手写 / 矢量底稿。
- 反过度禁用：正向设计必须强于 avoid 清单；如果 prompt 主要由 no / avoid / do not 组成，先重写正向设计。
- 符号：只写一条清晰主路线，控制密度，不写完整场景、完整地图、完整球场、完整城市、完整人群塞进字里。
- 英文 / 本地语言：如果需要，必须给准确文本和字体方向；如果不需要，明确 no subtitle / no extra words。禁止随机英文和伪文字。
- 纹理：正向词只用与路线匹配的 2D 表面语言，如 flat print、screen-print wear、ink grain、archival film grain、paper fiber、dry brush edge；不默认写 mud、dirt、cracked concrete、grunge、stone、metal。
- 文本：只出现准确标题和被批准的副标题，不加随机英文、水印、伪字。

不通过就重写 prompt，不能只在末尾补 Avoid。
