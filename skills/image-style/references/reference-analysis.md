# Reference Analysis

Use this when the user provides reference images. Do not copy a reference directly. Extract transferable design traits.

## Analyze each reference by role

For every reference image, identify:

- **Composition**: center, asymmetry, split field, diagonal, repeated modules, large negative space, collage, or full-bleed image.
- **Color**: palette family, saturation level, contrast, accent color, background tone.
- **Texture**: clean vector, paper grain, archival scan, hand-drawn, print texture, 3D, photographic, collage.
- **Light**: flat, soft, dramatic, documentary, studio, none.
- **Mood**: calm, serious, premium, handmade, playful, tense, reflective, institutional, historical.
- **Video usability**: readable at small size, overlay-safe zones, can support subtitles/charts, suitable as background or foreground.
- **What to reuse**: structure, palette, texture, mood, symbol logic, or hierarchy.
- **Transfer limits**: follow the requested use and permissions for the supplied reference; do not transfer unrelated subject matter or present generated material as factual evidence. Existing user assets being edited retain their specified invariants.
- **Input role**: distinguish style/composition reference, existing asset to reuse, and exact edit target; identify what must remain unchanged.

## Convert references into a style brief

Use this structure:

```text
Reference-derived direction:
- Reuse: <3-5 transferable traits>
- Avoid copying: <specific elements not to imitate>
- Asset role: <background / cutout / poster / infographic / data graphic>
- Visual direction: <one direction from visual-directions.md>
- Palette: <palette notes>
- Texture: <texture notes>
- Composition: <layout notes, compatible with layout-design>
- Prompt constraints: <must / avoid>
```

## Reference integration rules

- If references conflict, choose one dominant reference and one supporting reference.
- Do not average all references into a generic style.
- For finance explainer assets, preserve clarity over stylistic complexity.
- For documentary assets, avoid implying a generated image is archival truth.
- For transparent cutouts, references guide subject structure, style, and texture. Use native alpha when available and inspect edges; carry composition constraints only when the intended asset requires them.
