# Layout Principles

These principles are transformed into original project guidance from the scanned layout manual and the project's design workflow. Use them as practical rules, not as source text.

## 1. Communication before decoration

A layout is successful when it helps the viewer understand the message faster and feel the intended mood more clearly. Decoration is valid only when it improves hierarchy, rhythm, memory, or emotional connection.

Before designing, write one sentence:

```text
The viewer should first notice <primary message>, then understand <supporting message>, and finally remember <emotional impression>.
```

## 2. Information hierarchy

Treat every layout as four layers:

- **Primary information**: title, core claim, main visual symbol, or product name.
- **Main supporting information**: subtitle, date, location, CTA, author, brand, or category.
- **Secondary supporting information**: body copy, notes, credits, details, labels.
- **Image / graphic layer**: photo, illustration, shape, texture, line, symbol, or abstract field.

Do not style before assigning these layers. Size, weight, color, position, and motion must follow this hierarchy.

## 3. Japanese-inspired layout traits

Use these as tendencies, not clichés:

- **Simplify complexity**: reduce colors, keep the main subject clear, let the layout breathe.
- **Spatial atmosphere**: use negative space as an expressive field, not as leftover blankness.
- **Emotional restraint**: create feeling through proportion, rhythm, texture, and small tension rather than loud decoration.
- **Human care**: make reading comfortable; the layout should reduce effort for the viewer.
- **Order with a quiet twist**: establish a stable structure, then add one memorable asymmetry, crop, diagonal, texture, or symbol.

Avoid shallow Japanese cues such as random red circles, brush strokes, torii gates, or fake calligraphy unless the brief genuinely calls for them.

## 4. Contrast

Use contrast to create hierarchy and narrative.

Types of contrast:

- **Space**: dense vs open, near vs far, filled vs empty.
- **Typography**: large vs small, heavy vs light, formal vs handwritten, vertical vs horizontal.
- **Color**: muted base vs vivid accent, light vs dark, same hue with different brightness or saturation.
- **Texture**: smooth vs rough, flat vs tactile, photographic vs graphic.
- **Direction**: stable axis vs diagonal tension, vertical calm vs horizontal extension.
- **Scale**: oversized symbol vs small detail, full-bleed image vs tiny guide image.

Rule: contrast must clarify the focal point. If it only makes the page louder, remove it.

## 5. Repetition

Use repetition to create unity and professional reliability.

Repeat one or more of these:

- shape
- color
- line weight
- margin rhythm
- module size
- image crop ratio
- typographic treatment
- motion entrance pattern

Then introduce one meaningful variation:

- one element breaks scale
- one color becomes accent
- one module changes direction
- one image interrupts the rhythm
- one text block uses a different weight

Rule: repetition is not counting copies. It is building a visual system that makes one exception more noticeable.

## 6. Alignment

Alignment creates invisible relationships. Every element should connect to another through at least one of these:

- shared left, right, top, bottom, or center axis
- shared baseline
- shared grid column
- shared angle or curve
- shared margin
- intentional optical alignment with a shape or image edge

Use left alignment for readability, centered alignment for short ceremonial or poster-like text, two-sided alignment for formal density, and free alignment only when the visual system is already strong.

## 7. Proximity

Group related information physically close together. Separate unrelated groups with space, scale, or position.

Use proximity to form reading units:

- title + subtitle
- date + location
- product + claim
- image + caption
- logo + identity line
- numbered steps

If a viewer has to guess which detail belongs to which heading, proximity failed.

## 8. Negative space

Negative space can act as silence, luxury, tension, air, or focus. Do not fill it unless the content requires it.

Use negative space when:

- the main symbol or title needs authority
- the mood should feel restrained, premium, quiet, or poetic
- the image is small but meaningful
- the composition needs a pause before dense information
- the layout needs a sense of distance, mystery, or calm

The empty area must have a job. It can frame, isolate, balance, create tension, or guide the eye.

## 9. Image-text relationship

Text and image should form one visual sentence.

Common relationships:

- image as subject, text as anchor
- text as image, letterforms become the main graphic
- small image as guide, text carries the information
- image crop creates atmosphere, text provides interpretation
- repeated image fragments create rhythm or narrative
- symbol replaces literal explanation

Avoid pasting text on top of an image without a reason. Use image edges, empty zones, object direction, and tonal areas to place text.

## 10. Controlled rule-breaking

Break rules only after the basic order is visible.

Good reasons to break structure:

- create movement or urgency
- express instability, mystery, or humor
- echo the subject's shape or behavior
- create a memorable focal point
- make a static page feel cinematic

Bad reasons:

- hiding unclear hierarchy
- making the layout look more complex
- imitating a style without understanding it
- filling awkward blank space

## 11. Static-to-motion transfer

For HyperFrames or animated layouts:

- Design the strongest static frame first.
- Use motion to reveal hierarchy, not to compensate for weak spacing.
- When entrances are needed, give primary information the clearest motion path; content may also be fully visible from the start.
- Keep secondary information quieter; delay it only when the reading or narrative sequence benefits.
- Preserve alignment and grouping across scene transitions.
- Do not animate every element with the same pattern.

A motion layout should still make sense when paused at its hero frame.
