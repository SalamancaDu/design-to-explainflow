# Layout Patterns

Use this file to choose a composition pattern before writing prompts or building a layout. The patterns are adapted into original project rules from the layout manual's principles and case analysis.

## Pattern selection rule

Choose one dominant pattern and one optional secondary device. Do not combine several patterns just to look complex.

```text
Dominant pattern: <one layout structure>
Secondary device: <one supporting device>
Focal point: <what viewers see first>
Reading path: <where the eye moves next>
```

## 1. Quiet center with large negative space

Use when the mood should feel calm, refined, poetic, premium, or restrained.

Structure:

- small or medium focal object near center or optical center
- generous blank field around it
- supporting text placed on one clean axis
- restrained palette, often one accent color

Avoid:

- filling the blank area with decoration
- using too many text sizes
- adding unrelated icons or badges

## 2. Asymmetric subject with stable text anchor

Use when the image or symbol should feel fresh but still readable.

Structure:

- subject shifts left, right, top, or bottom
- text anchors the opposite or adjacent zone
- image and text share at least one edge, axis, or visual weight
- negative space balances the offset

Avoid:

- random floating text
- asymmetry without counterweight
- placing details far from their related heading

## 3. Split field

Use for comparisons, duality, before/after, tradition vs modernity, image vs text, or product vs story.

Structure:

- canvas split vertically, horizontally, or by a diagonal
- one side carries image or symbol
- the other carries hierarchy and details
- repeated margins keep both sides related

Avoid:

- equal visual weight when one side should lead
- splitting only because the page feels empty

## 4. Diagonal momentum

Use for motion, urgency, sport, youth, music, performance, surprise, or emotional tension.

Structure:

- main subject, type, or graphic follows a diagonal axis
- secondary information remains readable on a quieter axis
- supporting shapes echo the movement
- the direction implies an entrance, fall, rise, or push

Avoid:

- tilting every element
- sacrificing text legibility
- adding diagonal motion without a reason

## 5. Type as image

Use when the title, word, name, or character can become the main graphic.

Structure:

- letterforms occupy major visual area
- image, texture, or pattern may live inside or around the type
- supporting information is smaller and highly ordered
- the type treatment expresses the subject's mood

Avoid:

- dense body copy inside generated images
- decorative type that cannot be read
- using many unrelated fonts

## 6. Repeated modules

Use for series, collections, event programs, playlists, catalogs, or information-rich layouts.

Structure:

- repeated cards, dots, bars, image crops, frames, or text units
- one repeated variable changes: color, scale, image, spacing, or direction
- reading order remains predictable

Avoid:

- repetition without one standout element
- too many repeated element types
- equal emphasis across all modules

## 7. Small image as guide

Use when the design needs delicacy, documentation, architecture, maps, travel, craft, or editorial precision.

Structure:

- small image or icon leads the eye
- text carries the informational weight
- grid and margins are clean
- image acts as a signpost, not decoration

Avoid:

- enlarging every image to fill space
- losing the image-text relationship

## 8. Full-bleed image with text reserve

Use for cinematic posters, covers, hero images, and emotional scenes.

Structure:

- image fills the page
- reserve a calm text zone in low-detail area
- use tone overlays only if needed for readability
- align text to image edges, horizon, object direction, or empty field

Avoid:

- placing text over busy texture
- adding heavy overlays that kill the image mood

## 9. Corner masses around negative space

Use when you want a dynamic but clean composition.

Structure:

- visual masses sit in corners or edges
- central or off-center negative space becomes the breathing zone
- title or symbol may sit in the protected open area
- shapes feel like they frame the message

Avoid:

- letting corner elements compete with the title
- closing the space until it feels crowded

## 10. Geometric point-line-plane system

Use for architecture, art, music, data, tech, exhibitions, and abstract concepts.

Structure:

- dots, lines, bars, circles, rectangles, arcs, or planes form a visual system
- typography follows the same grid or axis
- one geometric element becomes focal
- repetition and variation create rhythm

Avoid:

- generic tech decoration
- random geometry with no hierarchy
- low-contrast thin lines in video output

## 11. Collage or montage narrative

Use for memory, surrealism, film, historical themes, travel, or layered storytelling.

Structure:

- multiple image fragments create a narrative field
- consistent crop style or texture keeps it unified
- text is anchored to a calmer zone
- one object or title remains dominant

Avoid:

- treating every fragment as equally important
- collage without a reading path

## 12. Motion title-card layout

Use for HyperFrames scenes, animated openers, subtitle cards, and video sections.

Structure:

- static hero frame has a clear primary title
- secondary information sits in one grouped block
- decorative motion elements trace existing axes
- when entrances are used, their order follows the intended reading path; an already-visible composition may use emphasis alone
- when a transition uses the outgoing scene, preserve its required content until that transition starts

Avoid:

- using motion to solve poor layout
- animating all elements in the same way
- unintended cuts or transitions that break the intended reading or narrative continuity
