# 每滴有数：四路由试跑输入

用途：面向普通中文读者的城市用水科普视觉练习。所有数值由本次试跑自拟，不用于说明现实家庭用水分布，也不构成节水建议。

共同方向：1920 × 1080；暖纸白、石墨色与低饱和绿色；一眼先见主标题，再读总量与分配。内容为「每滴有数」「100份水，用到哪里？」「先看去向，再谈节约」「2026.10 · 演练版」。数据为洗浴40份、厨房30份、洗衣20份、其他10份，合计100份。始终保留「演示数据 · 不代表真实用水统计」。文字和数字不允许改写。

这四条请求共用主题，但交付条件不同，不能为了覆盖四路由而把准确数据强行塞进 A：

| 请求 | 路由与所需输出 |
|---|---|
| 做无文字、无定量图形的水滴主题氛围整图；本轮只准备生成提示词 | A：layout-design → image-style → 提示词质量检查。imagegen 不执行 |
| 做完整用水分配静态图，标题、日期和数字可修改 | B：layout-design → HTML/SVG准确合成。image-style沿用已选配色；无需新位图 |
| 用B的完整静帧做6秒无声缓慢推近，所有信息开场可见 | C：静帧检查 → motion-style → 浏览器时间预览；不拆层、不导出视频 |
| 用B的可编辑结构做8秒无声逐项强调，保留完整数值和比例 | D：前期运动意图 → 复用B静态合成 → 元素交接 → motion-style → 浏览器时间预览 |

另用同一标题测试 title-text-design 的「仅提示词」分支，生成字形方案与透明资产提示词。B/C/D本轮明确使用普通可编辑标题；定制字形尚未生成，不把其计划路径交给下游。

实施能力：原生HTML/SVG/JavaScript及本机字体，不新增库，不使用HyperFrames，不调用生成服务。浏览器预览只运行页面动画，不执行视频编码或渲染命令。C/D明确无声，时长可固定；另测“后续配音但未给音频”时才标记时间轴暂定。

源文件与范围：preview.html 为本案例可编辑布局及预览源；B/static-export.svg 是初始静态导出快照。网页的日期试改仅存在当前预览，不写回文件。D manifest 是交接快照，不是运行时输入。C使用整帧图像对象，D使用可独立寻址的SVG组。
