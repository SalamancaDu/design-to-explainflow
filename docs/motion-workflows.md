# 整帧与逐元素动效

适用于短时图文动效、标题卡、解释片段和剪辑用资产。根据需要控制的元素选择整帧运动或分层制作；工具由项目和交付要求决定。

## C 整帧动效

已有整图只需推拉、裁切、整体移动、遮罩或新增叠加元素时使用。

~~~text
检查图片、尺寸与运动余量
→ motion-style：明确整帧动作、时长和停留
→ 选定工具实现
→ 预览、导出与检查
~~~

整帧方案不要求拆层或创建逐元素 manifest。不能承诺独立移动已经烘焙在图中的主体、标题和图表；出现这类需求时转 D。遮罩或叠加不会自动恢复图中被遮挡的内容。

## D 逐元素动效

~~~text
确认准确内容、交付要求和已有素材
→ layout-design + 运动意图：信息如何变化，哪些元素必须独立控制
→ image-style / title-text-design：建立或复用视觉母版
→ 按运动需求制作必要位图、准确文字和数据图形
→ 选定工具静态合成，得到 composite-preview 与定位说明
→ motion-style：元素动作、时间、停留、转场与音频依据
→ 实现工具制作实际动画
→ 检查预览与关键时间点
→ 导出目标文件
→ 检查导出结果并交付
~~~

## 两次动效判断

拆层前只确定运动意图：哪些元素变化、变化表达什么、是否需要遮挡关系、独立投影或背景补全。可由现有 brief 与 layout-design 直接给出；复杂运动再使用 motion-style 的前期规划。此时不要求先有完整分层或静帧。

详细动作和时间轴以已成立的静态合成为依据。运动意图发生变化时，只补受影响的素材和布局，不默认重做全部母版。

## 素材与可编辑内容

- imagegen：需要的背景、主体、材质和位图装饰；有原生透明能力时直接输出透明素材。
- 合成工具：准确文字、数字、图表几何、路线、标签、箭头、强调线和数据卡。
- 定制标题：可使用经逐字核对的独立透明资产，保存准确源文本；需要逐字动画时提前说明拆分粒度。
- 数据：真实数值驱动图形与标签；机制示意注明性质，视觉隐喻不承担事实证明。

## 进入详细动效的条件

- 静态 composite-preview 包含真实内容，层级和构图成立。
- 需要独立运动的元素已可分别控制；存在 manifest 或等价定位说明。
- 准确文字与数据已核对；标题位图的字符与边缘已检查。
- 时长、画幅、声音、导出格式和源文件需求已明确到足以实现。
- 明确声音模式：有实际音频时按其时长与节奏安排；明确无声时按约定时长定稿；计划配音但音频未到时，将受音频影响的时序标为暂定，不宣称精确对齐口播。

这些是质量条件，按任务实际需要检查，不自动增加用户审批节点。

## 实现、验收与返工

motion-style 交付方案，实现工具负责将其变成动画。使用 HyperFrames 时按[调用索引](skill-index.md)选定入口和版本，再执行相称的静态、运行与导出检查。

检查开始、信息齐全时、动作或场景交界、结尾及其他关键时间点；确认文字可读、无意外遮挡或裁切、媒体与声音正常、最终文件符合交付要求。工具检查通过不替代实际导出文件检查。

构图不成立回到 layout-design；素材不一致回到 image-style；动作导致读不清回到 motion-style 或实现；仅导出故障则修复导出层。硬切、停留和转场由叙事需要决定，不要求所有元素都入场或每个场景都使用特效转场。
