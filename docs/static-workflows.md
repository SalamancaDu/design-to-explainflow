# 静态整图与可编辑静态合成

用于封面、海报、视频配图、文章配图和单张信息图。最终交付静态图，不代表制作过程必须是单张不可编辑位图。

## 路由选择

| 路由 | 使用条件 | 最终交付 |
|---|---|---|
| A 静态整图 | 氛围、构图、主视觉为主，不需要内部元素单独修改 | 检查后的完整静态图 |
| B 可编辑静态合成 | 有准确文字、数据关系，或需要改字、替换素材、调整图形 | 静态导出图；按请求提供可编辑源文件 |

准确文字可以很少，但只要需要可靠修改或排版，就选择 B。无需为了改日期或数字进入动效流程。定制标题字按需调用 title-text-design；普通标题排版由 layout-design 与合成工具完成。

## A 静态整图

~~~text
确认内容与交付要求
→ layout-design：层级、构图与留白
→ image-style：视觉方向、参考图角色与位图提示词
→ imagegen：需要新生成或编辑位图时执行
→ 检查实际图像
→ 保存并交付
~~~

已有合适图片时可以复用。只有准确性要求允许的短装饰文字才随整图生成；若关键文字不可靠，改为 B 中独立排版，不继续依靠反复整图生成修字。

## B 可编辑静态合成

~~~text
确认准确内容、数据依据与编辑要求
→ layout-design：阅读顺序、排布、安全区域
→ image-style / title-text-design：只处理需要的视觉或定制字形
→ 建立或复用视觉母版，制作必要素材
→ 使用已有合成工具排入真实文字和准确图形
→ 检查 composite-preview
→ 导出静态图并交付所需源文件
~~~

文字、数字、矢量图形与位图各自承担适合的职责；HTML/CSS/SVG、现有设计文件或编辑工具均可，不默认绑定 HyperFrames。

真实图表的长度、面积、位置和连线关系也必须依据数据生成。仅把标签留到后期，不能保证图形准确。机制示意说明其示意性质；来源不足时不补造比例、时间或结论。

## 交接与检查

- 输入：用途、受众、比例或尺寸、准确文案、可改写部分、已有素材；涉及数据时附数值、单位、时间范围及来源或用户提供依据。
- 输出：实际文件、尺寸、所需格式、编辑源文件范围；提示词任务只交付提示词，不宣称图片已生成。
- 检查：主信息、阅读顺序、真实文字与数字、缩小后的可读性、裁切安全区域、素材边缘及最终导出。
- 字形问题回到 title-text-design；构图问题回到 layout-design；素材色彩或光线不一致回到 image-style；局部排版或数据错误修复对应源文件。

后续只做整图推拉可转 C；需要内部元素独立变化才转 D，见[动效链路](motion-workflows.md)。

## 启动提示词

~~~text
请完成一张[用途]静态图，尺寸或比例为[规格]。
准确内容：[不得改写的文字、数字、专名；其余可改写内容单列]。
素材与参考：[已有文件及各自用途]。
编辑和交付要求：[是否需要改字、替换元素、源文件及输出格式]。
先判断 A 静态整图或 B 可编辑静态合成，再使用必要的 Skill 完成请求。
保留准确内容；真实数据图形按数据绘制。视觉方向从主题和参考推导。
审阅节点：[仅填写我明确保留的节点；未保留时按授权连续完成]。
~~~
