# 能力与兼容范围

## 仓库提供什么

五个 `SKILL.md` 入口、17 份参考文件、5 份 Codex UI 配置，以及工作流文档与演示案例。它们帮助代理选择步骤和形成交接；执行能力来自所在环境。本项目没有模型服务、渲染引擎或自动批量视频生产后台。

| 层次 | 当前情况 |
|---|---|
| 工作流和提示词 | 可直接阅读或作为代理上下文；核心文档为中文，Skill 以中英混合编写 |
| Codex | 原始使用环境；包含 `agents/openai.yaml`，已有文件检查与本地案例记录 |
| 其他支持 Skill 的代理 | 可参考 `SKILL.md`；工具、安装目录、UI 元数据与触发行为需要在目标环境验证 |
| HTML/SVG/JavaScript 案例 | 不依赖前端库；通过本地 HTTP 服务预览 |
| Python 检查 | Python 3.10+，仅标准库；不需要 API 凭据 |
| 生图、透明资产、生成式视频 | 依赖外部服务和授权，本仓库未完成这些实测 |
| HyperFrames 或其他视频导出 | 按项目选定版本实施；案例不构成其兼容或成片验收 |

<a id="image-tools"></a>

## 图像工具

Skill 中的 `imagegen` 是原工作环境的能力名称，本仓库不安装该工具。使用者应自行提供图像生成 / 编辑能力，或只使用提示词与已有素材。

优先采用工具实际支持的原生透明输出；“PNG”并不自动等于含透明像素。准确文字和真实数据图形在合成阶段制作，不因换工具而放弃准确性要求。

<a id="motion-tools"></a>

## 动效工具

motion-style 负责设计意图与动作交接。执行可以使用已有代码动画、设计软件或剪辑软件。HyperFrames 只是其中一个选项。

对不同安装来源，使用与项目实际版本匹配的说明；不合并同名 Skill 的运行时约定，不隐式升级项目。自定义 manifest 是交接说明，除非项目已有读取器，否则不会自行变成动画。

## 平台说明依据

安装目录与发现机制参考 [OpenAI 的 Skill 文档](https://developers.openai.com/codex/skills/)；截至整理时，该文档列出项目级 `.agents/skills/` 与用户级 `~/.agents/skills/`。安装前以当前宿主文档为准，避免同时安装多个同名副本。

其他代理的兼容性尚未逐一验证。使用者可以从具体请求、工具能力和产物开始验证，而不是仅凭目录结构宣称兼容。
