# 常用提示词与复盘模板

替换方括号内容，只使用当前任务需要的模板。准确内容与交付范围优先；已有决定直接继承。以下阶段是质量依赖，不自动要求逐轮确认。

## 通用输入与交付

~~~text
目标与受众：[用途、要让观众理解什么]。
画幅与交付：[比例/尺寸、静态图或动效、格式、源文件需求；动效补时长和声音要求]。
准确内容：[不可改写的文字、数字、单位、专名、引文]。
可改写部分：[明确允许调整的文案]。
数据依据：[真实数据及来源/用户提供依据；无数据时说明只是机制示意]。
已有素材与参考：[文件及其作用：复用素材、编辑目标、构图参考或风格参考]。
视觉方向：[已选方向或需推导的主题语境]。
审阅节点：[仅填写明确保留的选择或审阅；没有则按已有授权完成请求]。
~~~

## layout-design

~~~text
使用 layout-design，基于已有输入确定信息层级、阅读顺序、主版式、排布和安全区域。
判断 A 静态整图、B 可编辑静态合成、C 整帧动效或 D 逐元素动效。
保持准确内容，仅改写被允许的文案。已有方向时直接深化，不重复输出候选。
涉及逐元素动效时，先说明哪些元素需要变化及变化的含义，供后续拆层使用。
~~~

## image-style 与视觉母版

~~~text
使用 image-style，继承已确定的版式与路由。
从主题和参考确定色彩、光影、镜头、材质、主视觉比例及留白。
有可用母版时直接复用；需要建立新方向时，给出或制作 master-frame-preview。
只为实际需要的非文字位图准备提示词，说明参考图角色与编辑时要保留的部分。
真实文字和数据图形交给合成工具；定制标题字按需交给 title-text-design。
~~~

## imagegen 母版与分层素材

~~~text
使用 imagegen，[生成新图/编辑指定素材]。
本次产物：[视觉母版/背景/独立主体/必要装饰]，用途与尺寸：[要求]。
参考或编辑目标：[实际文件和角色]。
继承：[色彩、光影、透视、纹理、镜头、主视觉比例]。
保留不变：[具体内容]；只调整：[本次变化]。
准确文字、精确数据几何和可编辑连线不烘焙进该位图。
独立素材需要透明时优先使用原生透明输出，检查实际 Alpha 与合成边缘。
将项目所需的选定素材保存到[项目目录]，报告实际路径和尺寸。
~~~

## title-text-design

~~~text
使用 title-text-design，处理准确标题“[标题]”，用途是[场景]。
已有方向或字体：[有则继承；没有则按完整交付要求选择合适路线]。
交付：[设计提示词/透明标题资产/二者]。
保留字体骨架、逐字字形、主题符号、缩小后可读性和生图可执行性的设计检查。
探索候选仅在我要求探索或存在实质选择时展开；展示内容按任务缩放。
透明导出优先采用当前工具的原生透明能力；仅在我明确保留预览审批时等待该节点。
~~~

## 可编辑静态合成

~~~text
基于现有素材和准确内容，使用项目已有合成工具完成静态画面。
文字与真实数据关系保持准确可编辑；定制标题资产须逐字核对。
先得到包含真实内容的 composite-preview，检查排版、尺度、对齐和合成边缘。
需要逐元素交接时补 manifest 或等价定位说明，明确坐标、路径和布局权威来源。
最终只要静态图时，完成导出与交付；进入动效时再交接详细动作。
~~~

## motion-style

~~~text
使用 motion-style，当前路由为[C 整帧动效 / D 逐元素动效]。
当前阶段：[拆层前运动意图 / 已有静帧后的详细动效 / 局部修改]。
素材、静帧与定位说明：[文件]；声音模式与时长：[明确无声及固定时长 / 实际音频与节奏依据 / 待配音及暂定时序]。
说明每个必要动作表达什么，给出入场或初始可见状态、强调、停留和结束方式。
保留已有风格；只有探索请求或实质取舍需要时比较候选。
明确无声时按约定时长完成；计划配音但音频未到时，将受影响的时序标为暂定。按信息需要选择初始可见或入场，不固定要求图形先于标签；转场、硬切、静止由叙事决定。
~~~

## 动效实现与导出

~~~text
根据已确定的静态合成和 motion brief，完成实际动画实现。
工具：[项目已有或已选工具]；使用 HyperFrames 时先确认项目版本和匹配入口。
继承现有 brief，不重新开启无关的风格采访。
完成相称的工具检查和关键时间点预览，再导出[格式、尺寸、帧率、声音等要求]。
检查实际导出文件，交付[成片、源文件等]。
准确区分方案、静帧、动画预览和最终导出的完成状态。
~~~

## design-review

~~~text
使用 design-review，审阅[实际产物]，用途为[用途]，下一步为[动作]。
按相关模式检查内容准确性、信息层级、视觉一致性及该产物的技术可用性。
指出有证据的问题、具体修复位置及是否具备下一步质量条件；没有问题可直接通过。
评分仅在有助于比较时使用，作品质量与经验沉淀价值分别判断。
已有授权内继续修复；用户明确保留的审阅节点仍需等待。
~~~

~~~~markdown

- 用途、受众和准确内容：

## 选定产物
- 母版与素材（按需）：
- 静态合成与布局源文件：
- 动效源文件与实际导出：
- 仍未完成或未验证的部分：

## 有效设计与修复
- 最有效的设计决定及原因：
- 实际问题、所属阶段和修复：
- 最终有效提示词或需要保持的设计约束：

## 可复用经验
- 经验及证据：
- 适用 / 不适用场景：
- 仅本次选择，还是值得提议更新已有规则：
~~~~
