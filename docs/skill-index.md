# Skill 调用索引

按交付和当前缺口选择最少必要的 Skill。四条路由见[工作流总览](overview.md)。本仓库提供五个设计 Skill；生图、合成、动画和导出由使用者已有或选定的工具执行。

| Skill | 什么时候用 | 交接给下游什么 |
|---|---|---|
| [layout-design](../skills/layout-design/SKILL.md) | 信息层级、阅读顺序、静帧构图 | 准确内容、布局约束、路由与必要运动意图 |
| [image-style](../skills/image-style/SKILL.md) | 非文字素材的视觉方向与生成准备 | 视觉约束、素材清单、参考图角色、位图提示词 |
| [title-text-design](../skills/title-text-design/SKILL.md) | 定制标题字形、片名字、标题资产 | 字体骨架、逐字结构、主题符号与准确源文本；普通排字不调用 |
| [motion-style](../skills/motion-style/SKILL.md) | 拆层前确定运动需求，静帧成立后细化动效 | 元素动作、时间、停留、转场、声音模式与实现交接 |
| [design-review](../skills/design-review/SKILL.md) | 请求审阅或有具体质量问题 | 有证据的问题、修复位置与下一步质量条件；评分和复盘按需 |

五个目录保留在同一层级，跨 Skill 的相对引用才能正常解析。安装方式见[开始使用](getting-started.md)。

## 外部能力与实现工具

- **图像生成 / 编辑**：文档中的 `imagegen` 指原工作环境中的生图入口；本仓库不包含其系统 Skill、模型、账号或额度。换用其他工具时，先核对参考图、编辑、透明输出和结果保存能力。
- **准确排版与合成**：使用已有 HTML/CSS/SVG、设计文档或剪辑工具。真实图表的几何与标签都依据数据制作。
- **动画与导出**：HyperFrames、已有网页动画或剪辑软件是可选实现。安装本仓库不会同时安装它们。
- **生成式视频**：按用户选择使用模型对应的入口，本系统提供视觉与动效意图，不自动改成代码动画。

详见[能力与兼容范围](compatibility.md)。

## 使用 HyperFrames 时

1. 保留用户指定的工具，读取项目说明、依赖和锁文件，确认实际实现版本。
2. 使用与该版本一致的官方文档或已安装 Skill；同名独立入口和托管插件可能不同，不合并两套运行时约定。
3. 用已有脚本或本地命令检查版本，不通过隐式安装或升级来探测，不自动修改托管插件缓存。
4. 继承上游已确定的 brief、素材、静态合成和动作意图；只补实现必需的缺口。
5. 按交付要求完成实现、预览、导出及实际文件检查。时间轴注册、字体、媒体和命令以选定版本为准。

设计交接字段见 [HyperFrames motion brief](../skills/motion-style/references/hyperframes-motion-brief.md)。该文件不包含运行时，不代表兼容性已经验证。

## 请求到路由

| 请求 | 处理 |
|---|---|
| 无需改字的氛围封面 | A；有需要才生成新位图 |
| 海报需要改日期、数字或标题 | B；准确排版后导出静态图 |
| 只做标题字形或透明标题 | title-text-design；按请求交付提示词或资产 |
| 已有整图做轻微推拉 | C；检查运动余量，无需逐元素拆层 |
| 主体、图表、标题分别变化 | D；先运动意图，再静态合成与详细动作 |
| 真实数据图 | 依据数据绘图；image-style 负责视觉方向与非数据素材 |
| 已有作品局部修改 | 进入负责该问题的阶段，不重跑无关环节 |

质量检查是执行判断，不自动增加审批。用户指定的审阅节点和真实外部操作授权仍须遵守。
